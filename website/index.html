Overview

What is sensor-app?

A complete end-to-end Industrial IoT stack, built phase by phase from a local MQTT broker to a cloud-native Kubernetes platform.

sensor-app is a fault-tolerant Industrial IoT monitoring platform designed for real engineering environments. It simulates PLC sensor data (temperature, pressure, flow rate, vibration), publishes via MQTT, and routes data through a resilient pipeline to AWS IoT Core, PostgreSQL, and Grafana dashboards.

Built across 10 phases — from a basic local broker to Kubernetes edge deployments with CloudWatch alarms and managed Grafana — sensor-app demonstrates production-grade IoT architecture for industrial use cases.

Developed by Splendid Technology Ltd, a Leicester-based engineering software company specialising in Industrial IoT and reliability engineering tools for SMEs.

Sensor Simulation

Realistic PLC sensor data generator simulating industrial equipment metrics.

MQTT Pipeline

Mosquitto broker with TLS and offline queue for fault-tolerant message delivery.

  • Local Mosquitto broker (plain + secure)
  • Offline queue with SQLite persistence
  • Auto-reconnect and replay on reconnect

AWS IoT Core Bridge

Secure device-to-cloud bridge with certificates, policies and IoT rules.

  • X.509 device certificates
  • IoT rules routing to DynamoDB + CloudWatch
  • AWS Managed Grafana dashboard
??

Kubernetes Deployment

Full K8s manifests for cloud-native edge IoT deployments.

  • Edge forwarder + ingestion API pods

Monitoring and Alerting
